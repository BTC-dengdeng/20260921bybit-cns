<p>因此，用 Bybit Card 消费前最好一起看：</p>

<ul>
<li>Card 计价货币；</li>
<li>Funding Account 持有哪些资产；</li>
<li>是否需要 USDT → 法币转换；</li>
<li>当前兑换费率；</li>
<li>当前外汇费用。</li>
</ul>
